# Contributing to Flipday

Thanks for wanting to help. Bug reports, ideas and code are all welcome.

## Reporting a bug

Open an issue and include:

- What you did
- What you expected to happen
- What happened instead
- Your browser and operating system

A screenshot helps a lot for anything visual.

## Suggesting a feature

Open an issue that describes the problem you want to solve, not only the solution. Flipday aims to stay calm and simple, so small, focused ideas are the easiest to accept.

## Making a change

1. Fork the repository and create a branch from `main`.
2. Follow the [setup guide](README.md#setup-guide) to run it locally.
3. Make your change. Keep it small and focused on one thing.
4. Run `npm run build` and make sure it finishes without errors.
5. Check your change in both the light and dark theme, and on a narrow (phone-sized) window.
6. Open a pull request that explains what you changed and why.

## Code style

- Match the style of the code around your change.
- Keep comments short, and only where the code is not obvious.
- Do not add a dependency unless it is really needed.
- Never send user data anywhere. Everything stays in the browser.

## Code of conduct

Be kind and respectful. Assume good intent, and keep feedback about the work, not the person.
